# 主页、设置和连接确认

- 主界面增加 Material 底部导航：主页、设置。同一 Activity 内切换两个内容容器，切换不重建连接或远控会话。
- 主页保留可控设备标题、连接状态、在线设备数、设备列表及空状态。
- 设置集中录屏自动授权开关、信令/TURN 配置入口以及无障碍和电池优化入口。服务器配置沿用已有表单、校验和持久化；权限已配置后仍保留入口。
- 导航选中项在 Activity 状态恢复时保留；首次启动默认主页。
- 点击设备仅弹出包含设备名称的确认框，取消不发起连接；确认后重新检查当前连接与设备在线状态，再调用 connectTo。重复点击不堆叠弹框，断线和页面销毁关闭弹框。
- 保留之前尚未提交的设备注册修复，当前改动不提交或部署远端。
