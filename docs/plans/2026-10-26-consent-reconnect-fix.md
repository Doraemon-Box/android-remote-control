# 反复远控后的授权状态恢复

原先会话结束只取消无障碍辅助操作，没有清除待处理录屏请求。若在授权返回前退出，后续会话会一直被“请先完成或取消当前屏幕录制授权”拦截。

改为对每次授权分配独立 Activity requestCode，并绑定请求所属 roomId。会话退出、信令断开、请求失败和页面销毁时，先清空待处理请求，再通过 finishActivity 关闭对应系统授权页。只消费当前 requestCode 的结果；旧回调不清理新请求，也不能授权新会话。Activity 在同一进程内重建后也不复用旧编号。

回归测试覆盖取消后重连、旧结果迟到、新请求只消费一次、连续取消以及页面重建后的编号隔离；实机循环覆盖正常采集退出和未授权即退出后重新连接。
