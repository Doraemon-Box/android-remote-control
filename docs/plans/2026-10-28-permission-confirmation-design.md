# 设置页权限变更确认

- 关闭录屏自动授权时，先保持原开关和持久化状态，再展示影响说明。只有确认后才保存关闭并取消待处理的自动授权；取消、返回或点击弹框外部均不改变配置。
- 无障碍服务已开启时，点击权限入口先说明关闭会影响点击、滑动及录屏自动授权，确认后再进入系统设置。
- 已获电池优化豁免时，点击入口先说明恢复优化可能造成后台离线，确认后进入系统电池优化管理页。未获豁免时继续使用原授权请求流程。
- 系统权限的实际撤销由系统设置完成，App 内确认覆盖从设置页发起的管理操作。
- 防止重复弹框，Activity 销毁时关闭弹框。

## 验证

- Debug 构建、Android Lint、资源 XML 解析和 `git diff --check` 通过。
- 已安装到 OPPO 真机：录屏自动授权关闭确认框正常显示，取消后开关仍开启；无障碍与后台运行两个管理入口均先显示影响说明及确认按钮，测试后保留原权限状态。
