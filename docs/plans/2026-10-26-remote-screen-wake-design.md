# 息屏远控唤醒

后台连接服务的 PARTIAL_WAKE_LOCK 只保证 CPU 运行，不唤醒显示屏。被控请求到达时，在申请录屏授权前持有单独的屏幕唤醒锁，兼容 Activity 已退到后台的情况；会话期间保持屏幕唤醒。

唤醒锁设置 60 秒超时，会话存续时每 30 秒续期。授权取消、会话结束、信令断开或 Activity 销毁时释放并取消续期。授权回调继续同一会话时不会重复创建唤醒锁。不改变待机时屏幕状态，也不尝试绕过密码锁屏。

验证使用 USB 真机 PKW120：先息屏，再由测试控制端发送远控请求，检查显示屏自动唤醒、录屏授权和采集状态；断开后检查唤醒锁释放，确保待机不会继续保持亮屏。
